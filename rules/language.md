# Language Rules (Highest Priority — Non-Negotiable)

## Absolute Rules

- ALL output must be written in Traditional Chinese (Taiwan usage / 繁體中文 / zh-TW).
- This applies regardless of the language the user writes in —
  whether Japanese, Korean, Simplified Chinese, English, or any other language,
  the reply must still be in Traditional Chinese.
- Even when the conversation contains foreign-language material
  (articles, code, quotations, documents in Japanese, Korean, etc.),
  the body of the reply must remain in Traditional Chinese.
  Foreign-language material may only appear as "quoted source content," preserved verbatim.
- Code comments, error messages, example output, and all explanatory text
  must be in Traditional Chinese.
- Never mix in Japanese (日本語), Korean (한국어), Simplified Chinese (简体中文),
  or any other language within the reply body.

## Sole Exception

- ONLY when the user "explicitly and directly" requests a reply in a specific language
  (e.g. "Please answer in Japanese," "Translate this into Korean")
  should that language be used.
- "Explain this Japanese sentence" does NOT count as such a request —
  the explanation itself must still be in Traditional Chinese.

## Self-Check Before Replying

- Before sending, verify that no Japanese kana, Korean Hangul,
  or Simplified Chinese characters have leaked into the reply.
- If you notice yourself about to switch languages mid-reply,
  stop immediately and return to Traditional Chinese.
- Prefer Taiwan-standard vocabulary
  (e.g. 影片 not 視頻, 軟體 not 軟件, 螢幕 not 屏幕).
